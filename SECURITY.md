# Security policy

## Reporting a vulnerability

If you find a security problem in this project, please do not open a public issue.

Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**. You can also email [YOUR EMAIL ADDRESS].

I will try to reply within [7] days and will credit you if you wish.

## Scope

This is a learning project. It is not intended for use in production.
