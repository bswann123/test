# Setup checklist

Work through this after you click **Use this template**, then delete this file.
Menu names on GitHub change from time to time, so look for the closest match.

## Your account (once)

- [ ] Turn on two-factor authentication (an authenticator app or a passkey).
- [ ] Save your recovery codes in a password manager.
- [ ] Add a short bio and a profile README (a repository named the same as your username).

## This repository

- [ ] Replace the placeholders in `README.md`, `SECURITY.md` and `LICENSE`.
- [ ] Update `.github/dependabot.yml` for the language you use.
- [ ] Keep the repository **private** until you have checked it for secrets and personal data.
- [ ] Never commit your real `.env` file. Copy `.env.example` instead.

## Settings to switch on

Open **Settings** and look under the security section (often "Advanced Security" or "Code security").

- [ ] Dependabot alerts
- [ ] Secret scanning and push protection
- [ ] Code scanning (default setup, using CodeQL)
- [ ] Private vulnerability reporting
- [ ] A rule on `main` that requires a pull request before merging

Some features are free for public repositories only. Check what your plan includes.

## Before you make it public

- [ ] Search your history for keys, passwords, real IP addresses and personal data.
- [ ] If anything leaked, rotate it first. Deleting a file is not enough.
- [ ] Check your course and supervisor rules on sharing assessed work.
- [ ] Pin the repository on your profile.
